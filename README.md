# Creative Embedded Design

Course projects for COMS BC3930: Creative Embedded Systems at Columbia University / Barnard College.

## Module 1: Stick Man (Grinding and Burnout)

Touching the wire makes a stick figure run faster while its health falls. At low health it slows down and the screen darkens. Releasing the wire allows gradual recovery. The button resets the figure after collapse.
